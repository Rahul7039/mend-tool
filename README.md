mend is one patch tool for every AI edit format: it reads a patch in JSON, JSONL, unified diff, SEARCH/REPLACE or V4A form, applies it to the working tree all-or-nothing, and reports exactly what changed.

## Run it

```sh
node main.ts your.patch
```
